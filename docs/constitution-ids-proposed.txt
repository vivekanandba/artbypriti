# Rule IDs this repository cites as PROPOSED but the constitution has not adopted.
#
# A citation to one of these is an honest record that this project proposed a rule, not a
# claim that the rule exists. Without this file the two are indistinguishable from a typo,
# and a gate that fails honest text gets switched off -- which this project has already
# written down twice.
#
# The exemption costs a sentence, deliberately. Format:
#
#   CON-XXX-NNN  <why this ID is cited before it exists>
#
# An entry here is WRONG once the rule is adopted: check-citations.py fails on an entry that
# now appears in constitution-ids.txt, because the citation should then stand on its own.
# It warns on an entry nothing cites, because a dead exemption is how an allowlist quietly
# becomes a blanket.
#
# All of these are in flight as vivekanandba/fleet#46 -- proposals only; adoption stays a
# separate human decision. docs/constitution-handoff.md has the detail.
#
# Note how fragile these numbers are: two have already had to change because the ID was claimed
# elsewhere while the proposal waited. That is itself one of the proposals in #46 -- a proposal
# should reserve no number at all, and the reviewer should assign it at adoption.

CON-DATA-006  Proposed by this repo (never fabricate domain content); CON-DATA defines 001-005, so 006 is genuinely next.
CON-PROC-010  Proposed by this repo (history is additive, now carrying a security-remediation exception). Verified safe to use: `git log -S` shows it has never named a rule, so it is a skipped number rather than a retired one.
CON-PROC-014  NOT ours, and not free: claimed by the open fleet/label-secrets-and-four-lessons branch ("A gate that cannot run is not a gate"). Cited only where this repo records why it could not be used.
CON-PROC-015  Proposed by this repo (verify from the commit), after CON-PROC-009 was adopted for another rule and 014 turned out to be taken too.
CON-VER-013   Proposed by this repo (a conformance tool passing is not the property you need), from the axe gate that stayed green on a planted alt="".
